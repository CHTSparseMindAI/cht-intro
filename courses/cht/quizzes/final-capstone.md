# Final Capstone

Goal: prove you can explain CHT with technical accuracy and customer-safe judgment.

Choose one capstone format.

## Option A: Technical Memo

Write a 2-3 page memo:

**Title:** What CHT Is, Why It Matters, And How To Prove It Works

Required sections:

- CHT in one paragraph;
- CHT vs pruning;
- CHT vs ordinary dynamic sparse training;
- CHT for Transformers and LLMs;
- hardware-aware N:M sparsity;
- dense-to-sparse recovery;
- evaluation plan;
- safe claims;
- claims to avoid.

## Option B: New-Hire Presentation

Create 8-10 slides:

1. SparseMind problem statement
2. CHT one-sentence definition
3. CHT learning loop
4. CHT variants
5. Hardware-aware sparsity
6. Recovery and distillation
7. Product proof metrics
8. Safe customer narrative
9. Open risks
10. Next experiment

## Option C: Product Proof Plan

Create a partner validation plan:

- partner scenario;
- model and baseline;
- sparse target;
- recovery/training plan;
- metrics;
- timeline;
- success criteria;
- risks;
- partner-facing claim.

## Review Rubric

| Category | Strong answer |
|---|---|
| Technical accuracy | Defines CHT as topology-guided dynamic sparse training |
| Distinction | Separates CHT from pruning, static sparsity, low-rank training, and N:M constraints |
| Evidence | Names the relevant paper family or source group |
| Product judgment | Does not overclaim sparse-over-dense or cost savings |
| Evaluation | Includes quality, hardware, memory, latency, energy if relevant, and stability |
| Communication | Uses plain English and avoids unnecessary jargon |
